# Multiwfn 光谱绘图操作手册

> **快速上手指南：** 本文档提供 Multiwfn 绘制各类光谱的核心流程与关键技巧

---

## 📋 一、Gaussian 关键词速查表

### 支持的光谱类型

| 光谱类型 | Gaussian 关键词 | 说明 |
|---------|----------------|------|
| **红外（IR）** | `freq` 或 `freq(anharm)` | anharm为非谐振 |
| **拉曼（Raman）** | `freq=raman` 或 `freq(raman,anharm)` | ⚠️ 注意：只有HF方法默认含raman |
| **预共振拉曼** | `freq=raman CPHF=rdfreq` | 文件末尾需写入射光频率 |
| **VCD** | `freq=VCD` 或 `freq(VCD,anharm)` | G16+支持非谐振 |
| **ROA** | `freq=ROA` | 文件末尾需写入射光频率 |
| **UV-Vis/ECD** | `TDDFT/TDHF/CIS/EOM-CCSD` | 激发态计算即可 |

**其他支持程序：** ORCA、sTDA、xtb、CP2K，或自定义txt文件

---

## ⚡ 二、核心操作流程（6步完成绘图）

```
步骤1: 启动 Multiwfn，载入输出文件
步骤2: 主菜单输入 11 → 进入光谱绘制
步骤3: 选择光谱类型
       1=IR  2=Raman  3=UV-Vis  4=ECD  5=VCD  6=ROA
步骤4: 设置展宽函数与 FWHM
步骤5: 调整坐标轴、单位、线宽等参数
步骤6: 输入 0 预览 → 满意后导出
```

### 🎯 快速操作示例

- **红外光谱：** `freq输出 → 11 → 1 → 0`
- **拉曼光谱：** `freq=raman输出 → 11 → 2 → 19(转换强度) → 0`
- **UV-Vis：** `TDDFT输出 → 11 → 3 → 0`

---

## 🔧 三、关键参数设置

### 展宽函数选择（重要！）

| 光谱类型 | 推荐展宽函数 | 说明 |
|---------|-------------|------|
| **电子光谱**（UV-Vis、ECD） | **Gaussian（高斯）** | 标准选择 |
| **振动光谱**（IR、Raman、VCD） | **Lorentzian（洛伦兹）** | 标准选择 |
| 混合需求 | Pseudo-Voigt | 可调比例 |

### 单位要求（必须正确！）

- **振动光谱**（IR/Raman/VCD）：能量和FWHM用 **cm⁻¹**
- **电子光谱**（UV-Vis/ECD）：能量和FWHM用 **eV**

---

## 💡 四、实用技巧清单

### ✅ 必做操作

1. **频率校正**：振动光谱绘图前必须乘以校正因子（菜单14）
2. **拉曼强度转换**：用菜单19将活性转为强度（更准确）
3. **数据导出**：菜单2导出X-Y数据，可用Origin等软件处理

### 🚀 进阶功能

- **菜单15**：分析各跃迁对特定峰的贡献
- **菜单16**：标注极值点位置
- **菜单23**：用竖线标注跃迁能级，颜色区分类型
- **multiple.txt**：批量绘制多个体系光谱对比

### ⚠️ 常见错误

- ❌ 未正确指定Gaussian关键词
- ❌ 单位错误（cm⁻¹ vs eV）
- ❌ 未选择合适的展宽参数
- ❌ 拉曼光谱未转换强度

## 📊 五、典型光谱操作流程

### IR（红外）

```bash
载入 freq 输出 → 11 → 1 → 14(频率校正) → 8(设FWHM) → 0(绘图)
```

### Raman（拉曼）

```bash
载入 freq=raman 输出 → 11 → 2 → 19(活性转强度) → 0(绘图)
```

### UV-Vis（紫外可见）

```bash
载入 TDDFT 输出 → 11 → 3 → 15(峰分解) → 2(导出数据) → 0(绘图)
```

### ECD/VCD/ROA

```bash
载入相应输出 → 11 → 4/5/6 → 选择表象/波长 → 调整参数 → 0(绘图)
```

## 📌 六、重要菜单选项速查

| 选项 | 功能 | 使用时机 |
|-----|------|---------|
| **0** | 预览/绘制光谱 | 设置完成后 |
| **2** | 导出X-Y数据 | 需用Origin处理 |
| **8** | 设置FWHM | 调整峰宽 |
| **14** | 频率校正因子 | **振动光谱必用** |
| **15** | 峰贡献分析 | 分析峰成分 |
| **16** | 极值点标注 | 突出峰位置 |
| **19** | 活性转强度 | **拉曼/ROA必用** |
| **23** | 跃迁能级标注 | 高级可视化 |
