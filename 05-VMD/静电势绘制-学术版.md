# 分子静电势的高效可视化：基于Multiwfn与VMD的自动化方法

*Efficient Visualization of Molecular Electrostatic Potential: An Automated Approach Based on Multiwfn and VMD*

## 摘要

本文介绍了一种基于Multiwfn和VMD软件的高效分子静电势可视化方法。通过自动化脚本和批处理文件，本方法显著简化了静电势可视化的操作流程，使研究人员能够快速生成高质量的范德华表面静电势图像和分子间穿透图。相比传统方法，本方法具有操作简便、计算高效、可视化效果优越等优势，适用于多种量子化学计算软件的输出文件。本文详细阐述了方法实现过程、参数优化策略以及在实际科研中的应用案例，为量子化学和分子模拟研究提供了重要的可视化工具。

## 1. 引言

分子静电势(Molecular Electrostatic Potential, ESP)是量子化学研究中的关键描述符，对分析分子间相互作用、预测反应位点和理解分子性质具有重要意义。静电势的可视化表征为理解分子体系的电子分布特性和预测其化学行为提供了直观的信息，在药物设计、催化研究和材料科学等领域有广泛应用。

传统的静电势可视化方法通常涉及复杂的手动操作流程，效率较低且可重复性差。本研究提出了一种基于Multiwfn和VMD的高效静电势可视化方法，通过自动化脚本显著简化了操作流程，提高了科研效率。

本文聚焦于两种互补的静电势可视化方法：

1. **表面顶点着色法**：通过Multiwfn的定量分子表面分析(主功能12)导出表面顶点文件(vtx.pdb)，并在VMD中根据B因子字段数据进行着色
2. **电子密度等值面映射法**：生成电子密度和静电势的cube文件，将静电势数据映射到电子密度等值面上

本研究采用Bader定义的范德华表面，即电子密度为0.001 a.u.的等值面。相比传统方法，本方法具有操作简便、计算高效、可视化效果优越等优势，尤其适合科研工作者使用。

> **引用说明**：使用本方法绘制的静电势图用于学术发表时，请引用Multiwfn程序原文，以及PCCP期刊上发表的Multiwfn静电势算法文章。若显示分子表面静电势极值点，请同时引用J. Mol. Graph. Model., 38, 314 (2012)，该文详细介绍了Multiwfn中搜索分子表面静电势极值点的算法。

## 2. 理论与方法

### 2.1 分子静电势理论基础

分子静电势定义为分子的核电荷和电子云在空间点r处产生的静电势的总和：

$$
V(r) = \sum_{A} \frac{Z_A}{|R_A - r|} - \int \frac{\rho(r')}{|r' - r|} dr'
$$

其中，$Z_A$为原子核A的电荷，$R_A$为原子核A的位置，$\rho(r')$为电子密度函数。

分子静电势是研究分子非共价相互作用的重要工具，尤其在分析氢键、卤键等弱相互作用中具有重要意义。正静电势区域（通常以红色表示）易与带负电荷的基团相互作用，而负静电势区域（通常以蓝色表示）倾向于与带正电荷的基团相互作用。

### 2.2 软件需求

本研究使用的主要软件包括：

- **Multiwfn**：波函数分析工具，推荐使用最新版本（官网：[http://sobereva.com/multiwfn](http://sobereva.com/multiwfn)）
- **VMD**：分子可视化工具，推荐使用1.9.3版本（官网：[http://www.ks.uiuc.edu/Research/vmd/](http://www.ks.uiuc.edu/Research/vmd/)）

### 2.3 输入文件要求

本方法支持多种量子化学计算程序的输出文件，包括但不限于：

- Gaussian：.fch/.fchk格式文件
- GAMESS-US、ORCA、Molpro等：.molden格式文件
- 其他支持的格式：.mwfn、.wfn、.wfx等

详细的输入文件类型信息可参考文献：《详谈Multiwfn支持的输入文件类型、产生方法以及相互转换》([http://sobereva.com/379](http://sobereva.com/379))。

### 2.4 自动化脚本系统

本研究设计了一套完整的自动化脚本系统，包括：

**批处理文件**（放置于Multiwfn目录）：

- `ESPiso.bat`：生成电子密度和静电势的cube文件
- `ESPpt.bat`：生成分子结构和表面顶点文件
- `ESPext.bat`：生成分子表面静电势极值点文件

**文本命令文件**（放置于Multiwfn目录）：

- `ESPiso.txt`、`ESPpt.txt`、`ESPext.txt`：分别对应各批处理文件的Multiwfn命令序列

**VMD脚本**（放置于VMD目录）：

- `ESPiso.vmd`/`ESPiso2.vmd`：绘制静电势填色等值面图
- `ESPpt.vmd`/`ESPpt2.vmd`：绘制静电势着色的分子表面顶点图
- `ESPext.vmd`：绘制分子表面静电势极值点

## 3. 实验方法

### 3.1 系统配置

1. 将批处理文件和文本命令文件复制到Multiwfn可执行文件所在目录
2. 修改批处理文件中的VMD路径为实际安装路径（若路径含空格，需使用双引号）
3. 将VMD脚本文件复制到VMD安装目录
4. 编辑VMD目录下的 `vmd.rc`文件，添加以下命令：
   ```
   proc iso {} {source ESPiso.vmd}
   proc iso2 {} {source ESPiso2.vmd}
   proc pt {} {source ESPpt.vmd}
   proc pt2 {} {source ESPpt2.vmd}
   proc ext {} {source ESPext.vmd}
   ```

### 3.2 单分子静电势图绘制实验

以乙酰胺分子为测试体系，演示两种不同风格的分子表面静电势图绘制方法：

#### 3.2.1 表面顶点着色法

1. 将分子的fch文件改名为 `1.fch`并放置于Multiwfn目录
2. 运行 `ESPpt.bat`批处理文件
3. 启动VMD，在文本窗口输入 `pt`命令

#### 3.2.2 电子密度等值面映射法

1. 运行 `ESPiso.bat`批处理文件
3. 启动VMD，在文本窗口输入 `iso`命令

#### 3.2.3 静电势极值点可视化

1. 运行 `ESPext.bat`批处理文件，额外产生一个记录极值点的 `surfanalysis.pdb`文件
2. 在VMD中显示静电势图后，输入 `ext`命令
3. 在Graphics - Representation里把Selected Molecule切换为density1.cub，把Material选项材质改为Transparent，此时背面的极值点才能看到。如果你想默认就用这种材质，把ESPiso.vmd里的$id EdgyGlass替换为$id Transparent即可

### 3.3 分子间范德华表面穿透图实验

#### 3.3.1 实验体系准备

对于分子复合物的穿透图绘制，实验流程如下：

1. 对复合物进行结构优化
2. 从优化后的复合物中提取各单体坐标
3. 对各单体进行单点计算，获取波函数信息（对Gaussian用户须添加nosymm关键词）
4. 将各单体的波函数文件分别命名为 `1.fch`、`2.fch`等

#### 3.3.2 实验案例

1. **Guanine-Cytosine碱基对**：通过 `ESPpt.bat`或 `ESPiso.bat`生成数据文件，通过 `pt2`或 `iso2`命令显示
2. **水四聚体**：使用四个水分子的fch文件，按照相同方法处理

## 4. 结果与讨论

### 4.1 单分子静电势可视化结果

乙酰胺分子的静电势可视化结果如图2所示。表面顶点着色法和电子密度等值面映射法各有特点：前者更为清晰直观，后者则提供更平滑的表面效果。

静电势极值点可视化结果显示，黄色球体表示静电势极大点（亲核反应位点），青色球体表示静电势极小点（亲电反应位点），可以直观展示分子的反应活性区域。

### 4.2 分子间相互作用可视化结果

Guanine-Cytosine碱基对的范德华表面穿透图展示了氢键形成区域的静电势互补性，红色（正电势）区域与蓝色（负电势）区域相互穿透，有力证明了氢键形成的静电相互作用本质。

水四聚体的静电势穿透图则清晰展示了水分子之间通过氢键网络形成的复杂相互作用模式，静电势互补特性明显可见。

### 4.3 参数优化与效果提升

#### 4.3.1 材质与色彩优化

对于复杂分子体系，材质和色彩参数的优化对可视化效果有显著影响：

1. **材质透明度调整**：通过VMD的 `Graphics - Materials`界面，选择当前用的材质EdgyGlass，调整Opacity（不透明度）参数，可以有效改善复杂体系的可视化清晰度
2. **色彩刻度方案**：除默认的蓝-白-红（BWR）配色外，也可选择红-白-蓝（RWB）或彩虹色谱（Turbo）等配色方案
3. **色彩刻度范围**：针对不同分子体系，特别是离子体系，应根据实际静电势分布调整色彩刻度范围

### 4.4 大型分子体系处理策略

对于原子数超过100的大型分子体系，建议采取以下策略：

1. **增加计算网格质量**：修改 `ESPiso.txt`的相关参数，提高格点密度
2. **使用低计算成本方法**：对于初步分析，可使用GFN-xTB方法优化结构并生成molden格式文件
3. **基于原子电荷的简化计算**：对于1000原子以上的超大体系，可采用基于原子电荷的静电势计算方法

### 其他细节

如果你目前还没根据自己机子实际情况修改Multiwfn的settings.ini文件里控制并行核数的nthreads参数，记得一定要将之改成CPU的物理核心数，要不然没法发挥CPU的实际计算能力。

本文的脚本的运行机制在《详谈Multiwfn的命令行方式运行和批量运行的方法》（[http://sobereva.com/612](http://sobereva.com/612)）中做了十分详细的介绍。希望大家充分理解脚本中的语句的内容，以便根据自己实际情况修改，从而用起来更方便，比如可以在ESPpt.bat和ESPiso.bat倒数第二行分别加上del D:\study\VMD193\*.pdb和del D:\study\VMD193\*.cub来使得运行时自动把VMD目录下之前的pdb和cub文件删除。

本文的.bat批处理文件是Windows下的，如果想在Linux下也类似地通过脚本快速绘制，看Multiwfn手册4.A.13节的第9部分（此外，也可以手动在性能较好的Linux服务器上把VMD脚本绘图所需的文件算出来，然后自行拷到Windows的VMD目录下再用VMD的脚本绘图）。

ESPpt.txt里的0.15是Multiwfn中定量表面分析时的格点间距，如果改大这个值，表面顶点就会变得更稀疏，同时由于表面顶点数变少了，计算耗时也会降低。ESPiso.txt里面的命令对应于计算电子密度和静电势格点数据时分别用high quality grid和low quality grid（后者低于前者是为了节约静电势计算时间），对于一般情况这个设置已经效果较理想了，但如果体系涵盖的空间范围特别大（比如400个原子以上），必须提升格点质量增加计算的格点数这样作图效果才好（当然代价是耗时显著增加），否则等值面可能很不平滑而且对应静电势的颜色很模糊。具体做法是把ESPiso.txt内容改为

```bash
5
1
4
0.4
0
5
12
2
2
```

本文最多考虑到了四聚体，更多聚体的穿透图也可以类似地绘制，比如绘制8聚体，就把ESPiso.bat和ESPpt.bat里计算命令的序号上限从4扩展到8，并且把ESPiso2.vmd和ESPpt2.vmd里的nsystem参数从4改成8，则运行这些绘图脚本时VMD目录下的后缀从1到8号的文件都会被载入和绘制。

#### VMD中静电势极值点的数目与Multiwfn不符

常有人问为什么他通过ext命令绘制出的分子表面静电势极值点的数目和他自己在Multiwfn里用主功能12做静电势的定量分子表面分析给出的不符，这是因为ESPext.bat脚本把格点间距设成了0.15 Bohr，而Multiwfn默认用的是0.25 Bohr。格点间距越小表面顶点确定得越准确。显然不符的时候，通过ESPext.bat给出的更准。如果想要二者结果一样，在Multiwfn主功能12里进行计算前先选选项3修改格点间距为0.15 Bohr即可。

对于巨型体系的分子表面静电势的绘制，DFT方法优化并产生波函数文件的过程可能比较费劲，但可以使用xtb程序在很便宜的GFN-xTB级别（类似于半经验的DFT方法）下做优化并产生molden格式的波函数文件，可以直接作为上文提及的脚本的输入文件。这在《巨大体系的范德华表面静电势图的快速绘制方法》（[http://sobereva.com/481](http://sobereva.com/481)）一文中介绍了。

如果你要绘制1000原子以上的特大体系的分子表面静电势图，像本文这样基于波函数来计算肯定是算不动的，应当使用《基于原子电荷极快速绘制超大体系的分子表面静电势图》（[http://sobereva.com/639](http://sobereva.com/639)）里的做法，用Multiwfn基于原子坐标和原子电荷来计算，虽然准确性会打一定折扣，但耗时超级低，对于几千原子体系在一般个人电脑上也就是耗费几分钟的事。

ESPiso.bat里有个-ESPrhoiso 0.001的设置，如果你想了解这是什么含义的话，参看《巨幅降低Multiwfn结合VMD绘制分子表面静电势图耗时的一个关键技巧》（[http://sobereva.com/602](http://sobereva.com/602)）。

如果体系带电荷特别多导致分子表面有的区域静电势数量级特别大，有可能导致ESPpt.bat涉及的vtx.pdb的B因子段落由于位数限制无法记录实际的静电势数值。解决办法是使用examples\drawESP目录下带_pqr后缀的那些文件代替前文提及的不带_pqr后缀的那些文件来计算以及在VMD中作图。带_pqr后缀的脚本会调用Multiwfn产生记录分子表面静电势的.pqr文件，其中charge那一列被用于记录静电势数值，由于没有位数限制，静电势无论多大都可以被记录（注意，总是以a.u.为单位记录）。

使用与本文类似的方法，还可以非常方便地绘制对于研究亲电反应位点非常重要的平均局部离子化能(ALIE)以及讨论亲核反应位点、亲电性非常有用的局部电子附着能（LEAE）着色的分子表面图，并且ALIE和LEAE表面极小点也可以一起显示出来，绘制过程见《使用Multiwfn和VMD绘制平均局部离子化能(ALIE)着色的分子表面图（含视频演示）》（[http://sobereva.com/514](http://sobereva.com/514)）和《使用Multiwfn通过局部电子附着能(LEAE)考察亲核反应位点、难易及弱相互作用》（[http://sobereva.com/676](http://sobereva.com/676)）。

很多次有人问怎么他用VMD渲染脚本（大概率是用的Multiwfn目录下的examples\scripts\VMDrender_full.bat）渲染出的分子表面静电势着色图太亮，白晃晃的。这是因为bat里渲染器选项用了-trans_raster3d，改成-trans_vmd就解决了，效果和Tachyon(internal)完全一样。

利用Multiwfn和VMD，还可以只对对应特定原子或片段的分子表面上的局部部分绘制静电势图，从而排除其它部分产生的视觉干扰，参见《使用Multiwfn结合VMD绘制分子局部区域表面静电势的方法》（[http://sobereva.com/750](http://sobereva.com/750)）。

## 5. 应用案例

本方法已在多项科研工作中得到应用，部分已发表成果包括：

1. **环状分子电子结构研究**：通过静电势分布分析18碳环和18氮环的电子特性（Carbon, 171, 514, 2021; ChemPhysChem, 25, e202400377, 2024）

该方法为分子静电势分析和可视化提供了强大工具，可广泛应用于药物设计、催化反应机理研究、分子识别与自组装等领域。相比传统的GaussView等商业软件，本方法具有更高的效率、更好的视觉效果以及更广泛的应用范围。
