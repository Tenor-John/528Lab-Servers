## 📊 集群资源概览

> 💡 **资源计算公式**
> 
> - **总 CPU 数** = `ntasks` × `cpus-per-task`
> - **总内存需求** = `mem`（或 `mem-per-cpu` × `ntasks`）

### 🖥️ 当前集群配置

| 资源类型 | 数量/容量 | 说明 |
|---------|-----------|------|
| **CPU 总核数** | 72 核 | 双路 18 核处理器 |
| **内存总量** | 31 GB | 系统可用内存 |
| **架构** | x86_64 | Intel/AMD 兼容架构 |
| **分区** | DFT | 密度泛函理论计算专用 |

## ⚙️ 2. Slurm 任务调度机制

### 🎯 调度策略

| 特性 | 说明 |
|-----|-----|
| **独立性** | 每个任务都是独立的 Slurm Job |
| **并行性** | 资源允许时自动并行运行多个任务 |
| **队列管理** | 资源不足时任务自动排队 |
| **隔离性** | 不同任务间完全隔离，不会相互干扰 |

### 📏 资源分配判断标准

> ⚠️ **并发运行条件：**

#### 条件 1：CPU 资源检查
```
每个脚本的 CPU 核数 × 同时运行数量 ≤ 72
```

#### 条件 2：内存资源检查
```
每个脚本的内存需求 × 同时运行数量 ≤ 31GB
```

#### 📊 实例计算

假设单个 VASP 任务需求：
- CPU: 16 核
- 内存: 8GB

**最大并发数：**
- CPU 限制：72 ÷ 16 = 4.5 → 4 个任务
- 内存限制：31 ÷ 8 = 3.875 → 3 个任务
- **实际并发：** min(4, 3) = **3 个任务**

## 📝 3. VASP 作业脚本编写

### 3.1 标准 VASP 脚本模板

```bash
#!/bin/bash
#SBATCH -J vasp-job                    # 作业名称
#SBATCH -o vasp-%j.out                 # 标准输出文件 (%j=作业ID)
#SBATCH -e vasp-%j.err                 # 错误输出文件
#SBATCH --partition=DFT                # 分区名称
#SBATCH --nodes=1                      # 节点数量
#SBATCH --ntasks=16                    # MPI 进程数
#SBATCH --cpus-per-task=1              # 每个任务的 CPU 核数
#SBATCH --mem=8G                       # 内存需求
#SBATCH --time=12:00:00                # 运行时间限制

# 环境设置
echo "=========================================="
echo "作业开始时间: $(date)"
echo "工作目录: $PWD"
echo "节点信息: $SLURM_NODELIST"
echo "CPU核数: $SLURM_CPUS_ON_NODE"
echo "=========================================="

# VASP 环境变量
export OMP_NUM_THREADS=1

# 运行 VASP
echo "开始 VASP 计算..."
srun vasp_std > vasp.log 2>&1

# 作业结束信息
echo "=========================================="
echo "作业结束时间: $(date)"
echo "=========================================="
```

### 3.2 高级脚本模板（带错误处理）

```bash
#!/bin/bash
#SBATCH -J vasp-advanced
#SBATCH -o logs/vasp-%j.out
#SBATCH -e logs/vasp-%j.err
#SBATCH --partition=DFT
#SBATCH --nodes=1
#SBATCH --ntasks=16
#SBATCH --cpus-per-task=1
#SBATCH --mem=8G
#SBATCH --time=24:00:00

# 创建日志目录
mkdir -p logs

# 错误处理函数
error_exit() {
    echo "错误: $1" >&2
    exit 1
}

# 检查必要文件
required_files=("POSCAR" "INCAR" "POTCAR" "KPOINTS")
for file in "${required_files[@]}"; do
    [ ! -f "$file" ] && error_exit "缺少文件: $file"
done

# 备份输入文件
backup_dir="backup_$(date +%Y%m%d_%H%M%S)"
mkdir -p "$backup_dir"
cp POSCAR INCAR POTCAR KPOINTS "$backup_dir/"

# 运行前检查
echo "预检查完成，开始计算..."
export OMP_NUM_THREADS=1

# 运行 VASP 并监控
timeout 24h srun vasp_std > vasp.log 2>&1
exit_code=$?

# 结果检查
if [ $exit_code -eq 0 ]; then
    echo "✅ VASP 计算正常完成"
    [ -f "CONTCAR" ] && echo "✅ 结构优化收敛"
    [ -f "OUTCAR" ] && echo "✅ 输出文件生成"
else
    echo "❌ VASP 计算异常结束 (退出码: $exit_code)"
fi
```

### 3.3 批量提交脚本

```bash
#!/bin/bash
# 批量提交多个 VASP 计算

# 工作目录列表
job_dirs=("structure1" "structure2" "structure3" "structure4")

for dir in "${job_dirs[@]}"; do
    if [ -d "$dir" ]; then
        echo "提交作业: $dir"
        cd "$dir"
        sbatch ../vasp_template.sh
        cd ..
        sleep 2  # 避免同时提交过多作业
    else
        echo "警告: 目录 $dir 不存在"
    fi
done

echo "所有作业已提交"
```

## 📊 4. 作业监控与管理

### 4.1 查看作业队列

```bash
# 查看个人作业
squeue -u torjohn528
```

**输出信息解读：**

```bash
JOBID PARTITION     NAME     USER ST       TIME  NODES NODELIST(REASON)
419348 CPU-64C25 vasp-job torjohn5 PD       0:00      1 (Priority)
419022 CPU-64C25 vasp-job torjohn5  R    5:55:50      1 cnode32
```

| 列名 | 含义 | 状态说明 |
|-----|------|----------|
| `JOBID` | 作业ID | 唯一标识符 |
| `ST` | 状态 | `PD`=排队 `R`=运行 `CG`=完成 |
| `TIME` | 运行时间 | 已运行的时间 |
| `NODELIST` | 节点列表 | 运行节点或排队原因 |

**常见状态码：**
- 🟡 `PD` (Pending): 排队等待
- 🟢 `R` (Running): 正在运行
- 🔵 `CG` (Completing): 即将完成
- ✅ `CD` (Completed): 已完成
- ❌ `F` (Failed): 失败
- 🔴 `CA` (Cancelled): 已取消

### 4.2 查看作业详细信息

```bash
# 查看特定作业详情
scontrol show job <JOBID>

# 查看作业工作目录
scontrol show job <JOBID> | grep WorkDir
```

### 4.3 批量查询作业位置

```bash
#!/bin/bash
# 查询多个作业的工作目录

jobids=(419022 419023 419028 419029 419031 419036)

echo "作业工作目录查询结果："
echo "======================================"

for jobid in "${jobids[@]}"; do
    echo "🔍 JobID: $jobid"
    workdir=$(scontrol show job $jobid 2>/dev/null | grep WorkDir | cut -d'=' -f2)
    
    if [ -n "$workdir" ]; then
        echo "   📁 工作目录: $workdir"
        # 检查关键文件
        if [ -f "$workdir/OUTCAR" ]; then
            echo "   ✅ OUTCAR 存在"
        else
            echo "   ⏳ OUTCAR 未生成"
        fi
    else
        echo "   ❌ 作业不存在或已完成"
    fi
    echo "--------------------------------------"
done
```

**示例输出：**
```bash

   📁 工作目录: /home/mmagroup/torjohn528/PbO2-cata/PbO2-211-2
   ✅ OUTCAR 存在
--------------------------------------
🔍 JobID: 419023
   📁 工作目录: /home/mmagroup/torjohn528/PbO2-cata/PbO2-211-2-Ovac-1
   ⏳ OUTCAR 未生成
--------------------------------------
```

### 4.4 实时监控脚本

```bash
#!/bin/bash
# 实时监控作业状态

watch_jobs() {
    while true; do
        clear
        echo "🕐 作业监控 - $(date)"
        echo "======================================"
        
        # 显示队列状态
        echo "📊 队列状态："
        squeue -u torjohn528 --format="%.8i %.10P %.15j %.8u %.2t %.10M %.4D %R"
        
        echo ""
        echo "💻 节点状态："
        sinfo --format="%.10P %.5a %.10l %.6D %.6t %N"
        
        echo ""
        echo "按 Ctrl+C 退出监控"
        
        sleep 30
    done
}

# 启动监控
watch_jobs
```

## 🛠️ 5. 常用管理命令

### 5.1 作业控制命令

```bash
# 取消作业
scancel <JOBID>

# 取消用户所有作业
scancel -u torjohn528

# 挂起作业
scontrol hold <JOBID>

# 恢复作业
scontrol release <JOBID>

# 修改作业时间限制
scontrol update JobId=<JOBID> TimeLimit=24:00:00
```

### 5.2 资源查询命令

```bash
# 查看分区信息
sinfo -o "%P %a %l %D %t %N"

# 查看节点负载
sinfo -N -o "%N %C %O %m %f %G"

# 查看作业历史
sacct -u torjohn528 --format=JobID,JobName,State,ExitCode,Start,End,Elapsed
```

### 5.3 性能分析命令

```bash
# 查看作业效率统计
seff <JOBID>

# 查看作业资源使用
sacct -j <JOBID> --format=JobID,MaxRSS,MaxVMSize,AveCPU,ElapsedRaw
```

## 🎯 6. 最佳实践建议

### 6.1 资源配置建议

| 计算类型 | 推荐 CPU 核数 | 推荐内存 | 预估时间 |
|---------|---------------|----------|----------|
| **结构优化** | 16-32 | 8-16GB | 6-24小时 |
| **单点能计算** | 8-16 | 4-8GB | 1-6小时 |
| **过渡态搜索** | 16-32 | 16-32GB | 12-48小时 |
| **分子动力学** | 32-48 | 16-32GB | 24-72小时 |

### 6.2 提交策略

1. **📅 时间管理**
   - 合理估算计算时间
   - 设置适当的时间限制
   - 避免浪费计算资源

2. **💾 数据管理**
   - 及时备份重要结果
   - 定期清理临时文件
   - 使用版本控制管理输入文件

3. **🔄 任务优化**
   - 根据系统负载调整并发数
   - 优先提交小任务测试
   - 使用 checkpoint 功能续算

### 6.3 故障排除

#### 常见问题及解决方案

| 问题 | 原因 | 解决方法 |
|-----|------|----------|
| 作业排队时间长 | 资源不足 | 减少 CPU/内存需求 |
| 计算中断 | 时间限制 | 增加 --time 参数 |
| 内存不足 | 内存超限 | 增加 --mem 参数 |
| 文件权限错误 | 权限问题 | 检查文件权限设置 |
